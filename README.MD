# Macroeconomic Forecasting & Economic Context Platform
An end-to-end macroeconomic forecasting system that ingests public economic indicators, generates explainable signals, trains and automates CPI forecasts, and supports both batch and on-demand predictions **for economic monitoring and decision support** using production-style data pipelines.


## Business Context
Financial institutions rely on macroeconomic indicators such as inflation, interest rates, and unemployment to support forecasting, stress testing, and forward-looking risk analysis.

These indicators are typically consumed by risk, finance, and analytics teams to assess economic conditions, evaluate portfolio exposure, and support planning under changing macroeconomic environments.

This project simulates a simplified version of how macroeconomic data can be ingested, transformed, interpreted, and forecasted to support downstream analytical and risk-based decision making.


## High-Level Architecture
High-level flow:

1. Macroeconomic data is ingested from public sources and stored in PostgreSQL
2. SQL views generate standardized economic features and trend signals
3. A backend API exposes:
    - Economic summaries
    - Plain-English interpretations
    - Forecast outputs
4. Machine learning models are trained and retrained via scheduled Prefect workflows with reproducible artifacts
5. Forecasts are generated both
   - On demand (user-triggered)
   - In batch (scheduled, stored for auditability and traceability)


## Deployment
This application is deployed using a container-based workflow on AWS:

- The frontend and backend are bundled into a single Docker image
- Images are stored in Amazon Elastic Container Registry (ECR)
- The application is deployed using AWS App Runner
- Environment-specific configuration (e.g. database connection) is injected via runtime environment variables
- The database is hosted on a managed PostgreSQL instance (Render)

## Data Ingestion & Feature Engineering
- Ingests CPI, interest rate, and unemployment series
- Computes MoM / YoY deltas
- Aligns time series across indicators to ensure consistent modeling windows
- Persists clean feature views in PostgreSQL
- Enforces non-null checks before modeling


## Economic Signals & Interpretability
Beyond raw metrics, the system generates economic “signals” that translate trends into plain-English interpretations.

Each metric includes:
- Trend direction (Rising / Falling / Stable)
- Latest value with units
- Short-term (MoM) and long-term (YoY) change
- Human-readable meaning and summary

An overall economic insight is generated by combining all three indicators to describe broader macro conditions.


## Forecasting Models
The forecasting component focuses on CPI as a core inflation indicator, given its central role in inflation-driven risk and policy analysis.

Separate linear regression models are trained for:
- 1-month horizon
- 3-month horizon
- 6-month horizon

Each horizon is modeled independently to reduce leakage and simplify evaluation.


## Automation & Prefect Workflows
Model training is automated using Prefect:
- Scheduled retraining runs when new data is available
- Model artifacts are versioned and overwritten in a controlled manner
- Training metadata is persisted for traceability

A separate batch prediction flow generates scheduled forecasts and stores results in the database for auditability and downstream consumption. 
<!-- Training and inference workflows are intentionally decoupled to align with production risk model governance practices. -->


## Data Quality, Controls & Validation
The system emphasizes data quality, validation, and process-level controls.

Key validation and control mechanisms include:
- Input data completeness checks (non-null enforcement prior to training and inference)
- Deterministic feature generation using centralized SQL views (MoM / YoY deltas, rolling statistics)
- Consistent feature sets across training and prediction to prevent leakage or schema drift
- Reasonableness checks through interpretable, horizon-specific models
- Separation of training, batch inference, and on-demand prediction workflows
- Persisted forecasts and training metadata to support auditability and traceability
- Controlled model overwrite behavior during automated retraining
